# 🏋️ FitLog — Workout Library

> **Train with intent. Log every set.**

FitLog is a modern workout library built for people who want to explore exercises, create a focused daily workout plan, and save their favorite workouts for later.

## ✨ Features

- 🏋️ **Workout Library** — Explore 12 workouts with muscle groups, equipment, difficulty, duration, calories, and ratings.
- 📋 **Daily Workout Plan** — Add workouts to today's plan with a maximum limit of 5 exercises.
- 🔖 **Save for Later** — Save workouts and access them anytime from the Saved tab.
- 📖 **Workout Details** — View detailed workout information and step-by-step instructions.
- ↕️ **Sort Workouts** — Sort workouts by duration, calories, or rating.
- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop screens.
- 🔔 **Toast Notifications** — Get instant feedback when adding, saving, removing, or completing workouts.

## 🛠️ Technologies Used

| Technology | Purpose |
| --- | --- |
| **Next.js** | Application framework and routing |
| **TypeScript** | Type-safe development |
| **Tailwind CSS** | Styling and responsive design |
| **React Icons** | Interface icons |
| **React Toastify** | Toast notifications |



## 🎯 Project Highlights

- Component-based architecture with reusable React components.
- Shared workout state management using React Context API.
- Dynamic workout data fetched from an external API.
- Responsive layouts using Tailwind CSS.
- Dynamic routing for individual workout details.
- Custom loading and 404 pages.
- Toast notifications for user actions.
